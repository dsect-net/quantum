# Tracker Board (React + @dsect/ui)

The rebuild of the Tracker board UI, tracked as **TRK-0267** (goal) under
the direction pinned on **TRK-0204**: React app in the quantum monorepo
using `@dsect/ui` from `dsect-net/design-system`, consuming the tracker
API. The stopgap `board_server.py` page stays live and untouched; this app
replaces it only when it has earned the swap (Scotty's call).

Plan: `~/workspace/tonight-2026-10-21/tracker-board-ui-plan.md`
(phases filed as TRK-0268…TRK-0273).

## Stack, following the root Quantum app's patterns

- Vite + React 19 + TypeScript (same toolchain versions as the root app).
- `@dsect/ui` consumed exactly like the root app: aliased to the
  `vendor/design-system` submodule source, component modules imported
  directly (never the bare entry). Kit CSS layers: fonts → tokens →
  base `layer(base)` → components `layer(components)`. Light theme is
  the kit default; the board is a light-first surface.
- App-specific layout lives in `src/board.css` and uses kit tokens only.

## Data

- **Board list:** the stopgap service has no JSON list endpoint, so the
  list comes from a snapshot generated by `scripts/snapshot-board.py`
  (the same queries `board_server.py` renders from; run it on Tritium
  and write the output to `public/board-data.json`). Phase P5
  (TRK-0273) replaces this with a real `GET /api/board`.
- **Item detail + edits:** live against the real service —
  `GET /api/item/<id>` and `POST /api/item/<id>/update` (same whitelist
  and validation as the stopgap page), reached through the Vite proxy.

## Run

Dependency resolution note: the kit's sources import `react` bare, which
resolves from an ancestor `node_modules` — in this repo that is the root
app's install (the same hoisting a workspace root would provide after
the MONOREPO.md restructure). If typecheck complains it cannot find
`react` from `vendor/design-system/react/src`, make sure the repo root
has its dependencies installed.

```sh
npm install
# item API target defaults to http://127.0.0.1:7654 (the board service).
# Developing off-box? Forward it first:
#   ssh -L 7654:127.0.0.1:7654 scott@tritium-linux
npm run dev        # http://localhost:5174
npm run build      # production build
npm run preview    # serve the build on :4174 (proxy included)
npm run snapshot   # regenerate public/board-data.json (on Tritium)
```
